💻 Sobre o Projeto
O PharmaDiag é uma plataforma web desenvolvida em Python com Flask para otimizar o processo de diagnóstico financeiro em farmácias. A ferramenta permite quegestores registrem informações de suas lojas e realizem diagnósticos de forma eficiente e digital.

🚀 Tecnologias
Backend: Python com o framework Flask

Frontend: HTML, CSS e JavaScript
